# Social posters

Generated by `gen2.py`. Every poster carries a scannable Google Play QR and the
install line, and every colour, font, number and content string comes from this
repo — so the posters cannot drift away from the app.

## Regenerating

```bash
./fetch-fonts.sh          # once — pulls the four faces from Google Fonts
pip install pillow qrcode --break-system-packages
python3 gen2.py           # writes out2/
```

Edit the content block at the bottom of `gen2.py` to change copy or add posters.

`cs-frm-countdown.png` is the only poster with a shelf life — the day count is
baked into the image. Change the `"58"` in the `cs_countdown(...)` call and
re-run before each use.
